## Hi, I'm Xuanliang Li 👋

我是一名数学专业大三的本科生，专注于数据科学和机器学习工程。拥有超过 5 年的编程经验。我喜欢将复杂的问题拆解成简单的数学模型并编写成可解释的程序解决方案。我坚信开源社区，并积极参与开源生态系统的发展。
